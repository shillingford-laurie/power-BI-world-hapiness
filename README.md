## World Happiness — Analyse Power BI

La synthèse de l'analyse est disponible dans le document PDF.


## Objectifs
  Nettoyer et préparer le jeu de données des scores de bonheur par pays.\
  Identifier les pays les plus heureux et les moins heureux.\
  Analyser les facteurs influençant le bonheur (PIB, soutien social, espérance de vie, liberté, générosité, corruption).\
  Comparer les régions du monde et l'évolution des scores.\
  Construire un dashboard interactif sous Power BI.\
  Restituer le travail collaboratif sous forme de page web.



## Technologies utilisées
    Excel 
    Power BI
    HTML5 / CSS3 / JavaScript
